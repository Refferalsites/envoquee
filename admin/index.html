      Email automation

      Provider: · From: · Admin notifications to:

      Until a provider key is set, every email is logged only (see the log below) and nothing breaks. To activate: connect a custom domain, create a free Resend account (or Brevo), verify the domain, then add Cloudflare Pages secrets RESEND_API_KEY (or BREVO_API_KEY), EMAIL_FROM (e.g. Envoquee <orders@yourdomain.com>), ADMIN_NOTIFY_EMAIL and optionally EMAIL_REPLY_TO, then redeploy.

      DNS records needed when your domain is connected
      • SPF (TXT on the sending domain or the provider's subdomain, e.g. send): Resend gives v=spf1 include:amazonses.com ~all; Brevo: v=spf1 include:spf.brevo.com ~all. Only one SPF record per name: merge includes if one exists.
      • DKIM: Resend gives a TXT record at resend._domainkey; Brevo gives brevo1._domainkey/brevo2._domainkey CNAMEs. Copy the exact values from the provider dashboard.
      • MX for bounces (Resend): send → feedback-smtp.<region>.amazonses.com priority 10, as shown in Resend.
      • DMARC (TXT at _dmarc): start with v=DMARC1; p=none; rua=mailto:dmarc@yourdomain.com, then move to p=quarantine once reports look clean.
      • In Cloudflare DNS set these records to DNS only (grey cloud).
