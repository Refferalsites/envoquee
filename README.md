# Envoquee — brand store (envoquee.pages.dev)

Static site generated by `build.py` (stdlib only) → `public/`, deployed to Cloudflare Pages by `.github/workflows/deploy.yml`.

- **Content:** `data/product.json` (price, sale price, stock, details, gallery, real reviews), `data/settings.json` (contact, shipping, returns, social, SEO), `content/blog/*.md` (front matter; future date = scheduled).
- **Functions** (`functions/api`): `order` (COD orders → KV `order:*`), `track`, `form` (contact → KV), `admin-login`, `admin-api`, `indexnow-hook`.
- **Admin:** `/admin/` — Orders (status, CSV), Blog, Product, Settings, SEO & Integrations, Auto Indexing, Messages. Edits are committed to GitHub and redeploy automatically.
- **Cloudflare Pages env:** KV binding `STORE`; secrets `ADMIN_USERNAME`, `ADMIN_PASSWORD_SHA256`, `SESSION_SECRET`, `GITHUB_TOKEN`, `INDEXNOW_HOOK_SECRET`; optional `GSC_SERVICE_ACCOUNT_JSON`, `MERCHANT_SERVICE_ACCOUNT_JSON`, `GOOGLE_INDEXING_SA_JSON`.
- **GitHub secrets:** `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `INDEXNOW_HOOK_SECRET`.

## Email automation (built in, log-only until activated)
Templates (editable/enable-able in Admin → Emails, stored in KV `email:config`): customer order confirmation, admin new-order alert, status emails (confirmed / shipped with courier + tracking / delivered / cancelled), contact auto-reply + admin alert, newsletter welcome, broadcast (with unsubscribe link + `List-Unsubscribe`), review request N days after delivery, abandoned-order reminder (off by default; only with the customer's email **and** ticked consent). Every attempt is written to the email log (KV `email:log`).

`.github/workflows/email-cron.yml` calls `POST /api/cron` every 6 hours (header `x-cron-secret` = `CRON_SECRET`, falling back to `INDEXNOW_HOOK_SECRET`).

**Activate:** connect a custom domain, verify it in Resend (preferred, free tier) or Brevo, then add Cloudflare Pages secrets `RESEND_API_KEY` (or `BREVO_API_KEY`), `EMAIL_FROM` (`Envoquee <orders@yourdomain.com>`), `ADMIN_NOTIFY_EMAIL`, optional `EMAIL_REPLY_TO`, and redeploy. Optional hooks: `SMS_WEBHOOK_URL`, `WHATSAPP_WEBHOOK_URL` (+ `HOOK_WEBHOOK_SECRET`), toggled in Admin → Emails (off by default).

**DNS records (Cloudflare DNS, grey-cloud / DNS only) — copy exact values from the provider:**
| Type | Name | Value (example) |
|---|---|---|
| TXT (SPF) | `send` (Resend) or `@` | `v=spf1 include:amazonses.com ~all` (Resend) / `v=spf1 include:spf.brevo.com ~all` (Brevo). One SPF record per name. |
| TXT / CNAME (DKIM) | `resend._domainkey` (Resend) / `brevo1._domainkey`, `brevo2._domainkey` (Brevo) | key from provider |
| MX (bounces, Resend) | `send` | `feedback-smtp.<region>.amazonses.com` priority 10 |
| TXT (DMARC) | `_dmarc` | `v=DMARC1; p=none; rua=mailto:dmarc@yourdomain.com` → later `p=quarantine` |
